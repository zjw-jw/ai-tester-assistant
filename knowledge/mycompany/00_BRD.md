# 商品管理系统 业务需求文档（BRD）

## 1. 项目背景
本系统用于管理电商平台上的商品信息，支持商品的创建、查询、库存扣减和删除。

## 2. 核心角色
- 管理员：拥有创建、查询、删除商品的权限。
- 普通用户：只能查询商品，不能创建或删除。

## 3. 业务流程
1. 管理员创建商品，系统分配唯一 ID。
2. 用户查询商品详情，用于展示或下单。
3. 下单成功后，系统扣减对应商品库存。
4. 商品下架后，管理员删除商品。

## 4. 业务约束
- 商品名必须唯一，不可重复。
- 价格范围为 0.01 ~ 99999.99 元。
- 库存范围为 0 ~ 9999 件。
- 扣减库存时不能超卖，且扣减数量必须为正整数。
- 删除商品后，不能再查询到该商品。

## 5. 验收标准
- 所有接口在正常流程下返回预期状态码。
- 边界值、异常流程、并发场景均有对应测试用例覆盖。
- 自动化测试通过率 100%（除已知缺陷外）。
